# TruEstate Frontend

## Overview
Modern React application for the Retail Sales Management System. Features a beautiful, responsive UI with smooth animations and intuitive user experience.

## Tech Stack
- React 18
- Vite
- Framer Motion (animations)
- Axios (API communication)

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Features
- Real-time search with instant feedback
- Multi-select filters with visual indicators
- Smooth sorting with dropdown interface
- Pagination with page navigation
- Responsive design for all screen sizes
- Beautiful animations and transitions
- Error handling and loading states
